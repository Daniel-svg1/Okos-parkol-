Egy okos parkolórendszer fejlesztése, amely lehetővé teszi a szabad parkolóhelyek megtekintését, foglalását.
A projekt jelenleg fejlesztés alatt van. 

A `version1` mappában Flask-alapú, kattintható belépőoldal található.
Indítás Windows alatt: `version1/inditas.bat`, majd `http://127.0.0.1:5000`.
A gombok egyelőre csak **Working on it** üzenetet jelenítenek meg;
bejelentkezés, regisztráció és adatmentés még nincs.
